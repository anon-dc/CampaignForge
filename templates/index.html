Setup SMTP Configuration

Configure your sending servers with this format. One server per line.

server|port|email|password|label|spoof_email|security

Example:

smtp.gmail.com|587|you@gmail.com|app_password|Gmail|you@gmail.com|TLS

Security types: TLS, SSL, NONE

Setup Recipient Format

Email addresses can be plain or with names. SMS numbers should be 10-digit.

email@domain.com email@domain.com,John Doe 6465386464

SMS carriers supported: AT&T, T-Mobile, Verizon, and more.

Campaign Creating Campaigns

Use personalization variables in your email content.

Hello {{name}}, Your account {{email}} is ready. Best, The Team

Variables: {{name}}, {{email}}, and custom tags.

Tracking Email Tracking

Add tracking pixels and click tracking to your emails.

<img src="http://localhost:80/tracking.html?mode=pixel&tid={{tracking_id}}" width="1" height="1"> <a href="http://localhost:80/tracking.html?type=click&tid={{tracking_id}}&url=https://example.com">Click Here</a>

Replace localhost:80 with your server address.

API REST API Endpoints

Programmatically manage your campaigns with these endpoints.

POST /api/smtp/upload - Upload SMTP configs
POST /api/recipients/upload - Upload recipients
POST /api/campaign/create - Create campaign
POST /api/campaign/start/{id} - Start campaign
GET /api/campaign/status/{id} - Get status
GET /api/tracking/stats - Get tracking stats
GET /api/stats - System stats

Settings Configuration Options

Adjust sending behavior and compliance settings.

Concurrent Workers: 1-10 (parallel connections)
Delay Between Sends: 0.1-5 seconds
Max Retries: 0-5 attempts
SMTP Timeout: 5-60 seconds
Daily Send Limit: 0 = unlimited
Auto-append Unsubscribe: Required for compliance
